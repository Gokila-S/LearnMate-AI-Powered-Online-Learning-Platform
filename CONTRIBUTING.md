# Contributing to LearnMate

Thank you for your interest in contributing to LearnMate! This document provides guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/online-learning-platform.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes thoroughly
6. Commit with clear messages
7. Push to your fork and submit a Pull Request

## Development Setup

See [README.md](README.md) for detailed setup instructions.

## Code Style

- Follow the existing code style
- Use meaningful variable and function names
- Add comments for complex logic
- Keep functions small and focused

## Commit Messages

- Use clear, descriptive commit messages
- Start with a verb (add, fix, update, refactor)
- Keep the first line under 50 characters
- Add detailed description if needed

## Pull Request Process

1. Update documentation if needed
2. Ensure all tests pass
3. Update the README.md if you add new features
4. Request review from maintainers

## Reporting Bugs

- Use the issue tracker
- Describe the bug clearly
- Include steps to reproduce
- Mention your environment (OS, Node version, etc.)

## Feature Requests

Feel free to suggest new features through the issue tracker. Explain the use case and potential implementation.

## Questions?

If you have questions, feel free to open an issue or reach out to the maintainers.
