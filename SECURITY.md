# Security Policy

## Supported Versions

Currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please send an email to security@learnmate.dev (or create a private security advisory on GitHub).

**Please do not create public issues for security vulnerabilities.**

### What to include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within 48 hours and work on a fix promptly.

## Security Best Practices

When contributing:

1. Never commit secrets, API keys, or credentials
2. Use environment variables for sensitive data
3. Validate and sanitize all user inputs
4. Keep dependencies updated
5. Follow OWASP security guidelines
